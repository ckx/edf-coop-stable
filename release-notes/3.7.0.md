# EDF6Coop 3.7.0

The game's chat word filter is off. The game replaces listed words with `*` at three points: when you confirm a typed message, when it sends a message and when it receives one. 3.7.0 replaces the filter call at all three with a no-match result, so nothing you type, send or receive is changed. `[Chat] WordFilter=1` keeps the game's filter.

- Only your own game changes. A player without the plugin still sees filtered text from everyone, since their own game filters what it receives. Two players on 3.7.0 see each other's messages as typed.
- The word check of the room settings' free word is untouched.
- The three call sites are verified before anything is written; if another mod changed them, the filter stays on and the log says so.

Netcode protocol 4 and the wire format are unchanged: 3.7.0 plays with 3.0.1 to 3.6.3.

This package is the clang/MinGW-w64 build tested under Wine, not an MSVC release build. The non-stress tests passed under Wine, including the plugin load tests against the real `EDF.dll`, which check the three sites with the filter off and with `WordFilter=1`. Whether chat shows as typed in a live room is not yet verified; if a message still shows `*` or the chat box misbehaves, note the time and attach `EDF6Coop.log` (its lines start with `CHAT`).

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
