# EDF6Coop 3.6.0 network sync diagnostic

This prerelease collects matched laser messages and changes the locked spectator camera. It does not replace the latest stable release.

- The locked spectator camera smooths received aim on foot and follows the seated teammate's heading in vehicles. Free-camera controls, W/E switching and the HUD keep their existing behavior. Vehicle gun aim can differ from the seat heading.
- Laser diagnostics log native projectile IDs, owner sends, decoded message fields and post-receive state. Type 0/3 messages carry velocity followed by position. These messages are conditional, so missing receive callbacks do not mean shots were lost.
- Player tracks hold mission-transition copies and reset when room identities change. Invalid LinkTimeoutMs and GraceSeconds values now warn and use the documented defaults. Late packets below a Forward floor no longer inflate duplicate counts. Empty stranded queues avoid locks on the common send path.

For the laser capture, both players install this package and keep `[Diagnostics] Laser=1`. In a new online room, fire one Closed Laser M2 shot at a distinct point, then wait at least 31 seconds before the next shot. Repeat while turning and, if reproducible, with the reported wall/ant discrepancy. Close the game and collect both logs. Match owner and bullet ID before comparing samples; match message type and hash for sent/received events. Logging limits can omit a counterpart.

For the camera check, go down online, press E, and watch a teammate turn on foot, enter a vehicle, turn it and get out. Check W cycling, E switching, revival and leaving the room. Smoothness and vehicle-seat orientation still need this live check.

The package contains the MSVC build. Both toolchains and the non-stress suites are checked against the supported EDF.dll. Stress tests are excluded from this diagnostic validation. Automated tests do not establish live multiplayer behavior; the matched two-machine capture and camera acceptance remain pending.

Windows: extract the whole package and run INSTALL.bat, or copy its contents beside EDF6.exe. Proton: extract the package and run install.sh, preserving your existing settings. Keep the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
