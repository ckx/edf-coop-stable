# EDF6Coop 3.1.1

The installers now uninstall a standalone EDF6Spectate. Its spectator camera is part of EDF6Coop since 3.1.0.

- `INSTALL.bat` and `bash install.sh` delete `Mods/Plugins/EDF6Spectate.dll`, the `EDF6Spectate.dll.disabled` copy that 3.1.0 left, and `EDF6Spectate.log`. 3.1.0 only renamed the DLL. EDF6Spectate had no settings file.
- Old `EDF6DirectNet.dll` and `EDF6MultiSlot.dll` are still renamed to `.disabled`, and their settings files stay.
- The plugin itself is unchanged apart from its version. If it finds `EDF6Spectate.dll` at game start, it still renames it to `.disabled`, since a DLL the game may have loaded cannot be deleted. The next installer run removes that copy.

Netcode protocol 4 and the wire format are unchanged: 3.1.1 plays with 3.0.1 to 3.1.0.

This package is the clang/MinGW-w64 build tested under Wine, not an MSVC release build. All 29 non-stress tests passed under Wine, including the tests against the real `EDF.dll` and the multi-process rooms. The installers were run against a test game folder on Linux (`install.sh`, and `install.ps1` under PowerShell 7), not on Windows.

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
