# EDF6Coop 3.0.3

Health pickups appear white on the minimap. Armor, weapons and all other pickups appear green. This applies with the default `[Display] RadarItemColors=1`; setting it to `0` keeps every pickup green.

This release retains 3.0.2's player movement fixes and Closed Laser M2 diagnostics. The radar change affects only your own display. Netcode protocol 4 is unchanged, and 3.0.3 remains compatible with 3.0.2.

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
