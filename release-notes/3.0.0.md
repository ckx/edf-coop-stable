# EDF6Coop 3.0.0

## English

3.0 keeps only the networking fixes and plays the game's own rooms of up to four players.

- Kept: lost game packets are resent (the desync fix), a short connection drop is hidden while EOS reconnects, the optional direct link to the host, the shooter deciding hits and player positions with velocity (when everyone runs 3.0), the weapon guard, the peer-timeout fix and the crash log.
- The direct link now carries game data only while the host answers. When it stops answering for about 1.5 s, what it had not delivered goes over EOS and play continues there until the link answers again.
- Removed: bigger rooms (Player MOD), the room screen, weapon pages, room weapon files, armor copy and the automatic updater. If you need them, stay on 2.5.0.
- Linux (Steam Proton): `install.sh` installs and uninstalls. Set the game's launch options to `WINEDLLOVERRIDES="winmm=n,b" %command%`. A host under Proton now advertises its address.

Everyone in a room must run 3.0. Its netcode and direct-link protocols differ from 2.5.0, and with the default `[Netcode] RejectMismatched=1` a host removes a player on the other version. The 2.5.0 updater does not offer 3.0: install it by hand. Your settings are kept.

Install: extract the whole zip. On Windows run `INSTALL.bat`; on Linux run `bash install.sh` and set the launch option above. `README_EDF6Coop.txt` in the zip has the details.

Tested with the automated suite on Windows (MSVC) and Linux (Wine), including multi-process rooms against the real `EDF.dll`. This version has not been tested in live multiplayer.

## 中文

3.0 只保留联机修复，使用游戏原本最多 4 人的房间。

- 保留：丢失的游戏数据包会重发（防不同步的修复）、EOS 重连期间隐藏短暂断线、可选的房主直连、射击方判定命中和带速度的玩家位置（全员 3.0 时）、武器保护、对端超时修复和崩溃日志。
- 直连现在只在房主有应答时承载游戏数据。约 1.5 秒没有应答时，未送达的数据改走 EOS，游戏在 EOS 上继续，直到直连恢复应答。
- 已移除：大房间（Player MOD）、房间画面、武器页、房间武器文件、护甲复制和自动更新。需要这些功能的人请继续用 2.5.0。
- Linux（Steam Proton）：用 `install.sh` 安装和卸载。游戏启动选项设为 `WINEDLLOVERRIDES="winmm=n,b" %command%`。Proton 下的房主现在会公布自己的地址。

同一房间的人必须都用 3.0。它的联机协议和直连协议与 2.5.0 不同，默认 `[Netcode] RejectMismatched=1` 时房主会移除另一版本的玩家。2.5.0 的自动更新不会提供 3.0，请手动安装。设置会保留。

安装：完整解压 zip。Windows 运行 `INSTALL.bat`；Linux 运行 `bash install.sh` 并设置上面的启动选项。详见 zip 里的 `README_EDF6Coop_zh.txt`。

已在 Windows（MSVC）和 Linux（Wine）上通过自动测试，包括用真实 `EDF.dll` 的多进程房间测试。此版本没有经过实际多人联机测试。
