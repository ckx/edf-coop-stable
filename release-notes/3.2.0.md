# EDF6Coop 3.2.0

Press Space while you are down to watch the next standing teammate.

- The spectator camera moves to the next standing teammate in slot order and wraps round. The one you chose stays watched until they go down or leave; then the camera moves on as before.
- Space is ignored while the chat box is open, so a typed space only goes into the message. It is also ignored while another window has the focus and while you are standing. Keyboard only, not rebindable.
- Three more ranges of the game's text-entry code are checked by hash before the camera is installed. If another mod changed them, the spectator camera stays off and `EDF6Coop.log` names the range; everything else runs.

The key and the chat-box check come from static analysis of `EDF.dll` and have not been checked online. If the camera cycles when it should not, or does not cycle, note the time and attach `EDF6Coop.log` (its lines start with `SPECTATE`).

Netcode protocol 4 and the wire format are unchanged: 3.2.0 plays with 3.0.1 to 3.1.2.

This package is the clang/MinGW-w64 build tested under Wine, not an MSVC release build. All 29 non-stress tests passed under Wine, including the tests against the real `EDF.dll` and the multi-process rooms.

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
