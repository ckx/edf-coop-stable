# EDF6Coop 3.2.1

The key that moves the spectator camera to the next standing teammate is now W instead of Space.

- Press W while you are down to watch the next standing teammate. Holding W as you go down does not count as a press; release it and press again.
- W is ignored while the chat box is open, so a typed w only goes into the message. It is also ignored while another window has the focus and while you are standing. Keyboard only, not rebindable.
- On a keyboard layout where W is elsewhere (AZERTY), the key is the one labelled W.

The key has not been checked online. If the camera cycles when it should not, or does not cycle, note the time and attach `EDF6Coop.log` (its lines start with `SPECTATE`).

Netcode protocol 4 and the wire format are unchanged: 3.2.1 plays with 3.0.1 to 3.2.0.

This package is the clang/MinGW-w64 build tested under Wine, not an MSVC release build. All 29 non-stress tests passed under Wine, including the tests against the real `EDF.dll` and the multi-process rooms.

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
