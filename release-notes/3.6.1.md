# EDF6Coop 3.6.1 facing diagnostic

- Shows `W: switch player / E: switch camera` at the bottom while spectating in either mode.
- Shows the running mod version in the bottom right of the online room screen.
- Adds paired native aim and remote-facing observations under `[Diagnostics] Player=1`, which is on by default. These help distinguish received aim from a character turning locally after a hit.

The backwards-facing report from 3.6.0 remains unresolved. This prerelease adds evidence collection; it does not change aim, ragdoll physics or the network protocol. It can share a room with 3.6.0, but everyone needs 3.6.1 for a complete diagnostic capture.

If it happens again, note the time, watched player and camera mode. Close the game and collect EDF6Coop.log from all players before another long session replaces the earlier lines.
