# EDF6Coop 3.5.0

While you watch a teammate after going down, their name now shows at the top of the screen, in both spectator camera modes.

- The name is the one the game's name indicators show for that player, including the platform name in brackets when the game's setting asks for it. It changes when W moves the view to another teammate and goes when you are revived.
- It is drawn with the game's own HUD font and text calls: the game's rescue message widget is attached to each spectator camera and draws the name instead of its own text. Your own camera's rescue message is not affected.

Install checks the rescue message's vtable and twenty more code ranges before changing anything; if another mod changed them, the spectator camera stays off and the log says so.

Netcode protocol 4 and the wire format are unchanged: 3.5.0 plays with 3.0.1 to 3.4.0.

This package is the clang/MinGW-w64 build tested under Wine, not an MSVC release build. All 29 non-stress tests passed under Wine, including the tests against the real `EDF.dll` and the multi-process rooms. Where the name lands, its size and whether it shows in a live room are not yet verified: `docs/spectate/plan.md`, M12 lists the checks. If it is missing or the game crashes while you are down, note the time and attach `EDF6Coop.log`; `[Display] SpectateWhenDown=0` turns the spectator camera off.

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
