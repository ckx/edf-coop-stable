# 3.0.1

- Keep enemy and object damage on the shooter's machine with the game's original collision data. Forwarding these hits discarded collision parts needed for armor and weak-point checks, which could leave accepted hits doing no damage. Other players and vehicles still receive shooter-decided hit events at their owners.
- Carry the current vehicle driver's authority through the game's damage check, even when the host owns the vehicle's network identity.
- Report completed hit replays separately from actual HP reductions in the `NetHit` log.
- Use netcode protocol 4. Everyone in a room must update together to use these fixes.

The reported joiner Plasma Cannon failure still needs confirmation in live multiplayer. The logs showed successful hit forwarding but did not record weapon names or actual HP reductions.
