# EDF6Coop 3.4.0

The watched teammate's health bar now shows in both spectator camera modes.

- Up to 3.3.0 the bar was attached to every spectator camera but the game hid it on the free camera: the game hides a camera's HUD while that camera orbits, which is how your own camera behaves while you are down. The plugin now answers that question itself for cameras that follow a teammate, so the bar stays on the free camera and the locked camera alike. Your own camera is not affected.
- The rule from here on: whatever the spectator camera shows, it shows in both modes. Energy for Wing Divers, a caption with the watched teammate's name and ammo are planned in that order.

Install checks the ghost camera's vtable slot and two more code ranges before changing anything; if another mod changed them, the spectator camera stays off and the log says so.

Netcode protocol 4 and the wire format are unchanged: 3.4.0 plays with 3.0.1 to 3.3.0.

This package is the clang/MinGW-w64 build tested under Wine, not an MSVC release build. All 29 non-stress tests passed under Wine, including the tests against the real `EDF.dll` and the multi-process rooms. Whether the bar appears in a live room is not yet verified: `docs/spectate/plan.md`, M11 lists the checks.

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
