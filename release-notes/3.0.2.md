# EDF6Coop 3.0.2

Fixes unnecessary forward/backward player corrections when frame times vary. The motion estimator now measures velocity over the actual elapsed time, including frame hitches. This fixes the regression reproduced from the timing patterns in the joiner and host logs; the improvement in live multiplayer still needs verification.

The default prediction limit is 350 ms, retaining diagnostic 5's setting. Explicit `[NetPlayer] MaxExtrapolateMs` values in an existing INI are preserved. Longer prediction covers short update gaps but can overshoot during an unseen stop or turn. The 400 ms stale-data fallback, correction limits and protocol 4 wire format are unchanged.

Adds bounded diagnostics for `LaserBullet01`, the projectile class used by Closed Laser M2. They record beam position and direction, age and lifetime, endpoints and render dimensions, owner identity when available, native receive callbacks and draw callbacks. Other weapons using that class also appear. This is instrumentation, not a confirmed laser synchronization fix, and does not change firing or damage.

Diagnostics are enabled by default. Set `Laser=0` under `[Diagnostics]` in `Mods/Plugins/EDF6Coop.ini` to disable them, then restart the game. At most eight snapshots are written per 30 seconds, with activity summaries while lasers are active. A draw callback is not proof of visible pixels; an early zero count is not proof of a missing beam. Receive callbacks are not a count of all replicated shots. Damage synchronization is not established by these samples.

For the next test, have Charles and the observers use this version. Fire Closed Laser M2 while stationary, then while turning and moving. Note the time of a mismatch and whether the beam, damage, or both differ. Close the game and collect everyone's `Mods/Plugins/EDF6Coop.log`. The startup line should say `LASER diagnostics ON`.

Extract the whole package and run `INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing settings and other mods are preserved. Proton needs the Steam launch option `WINEDLLOVERRIDES="winmm=n,b" %command%`.
