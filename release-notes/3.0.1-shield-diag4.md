# EDF6Coop 3.0.1 shield and player jitter diagnostic 4

This diagnostic prerelease investigates invisible Luminous Shields and player jitter. It fixes missing player-jitter summaries in diagnostic 3. Remote NPCs could displace player measurements before the five-second window finished; only players can now enter those diagnostic slots. Shield particle counts read as `unknown` when no matching particle buffer was measured. Gameplay and the protocol remain unchanged; this does not contain a shield or jitter gameplay fix.

Download `EDF6Coop-3.0.1-shield-diag4-full.zip` for the complete installation. It includes the plugin, fixed EDFModLoader, Windows and Proton installers, uninstallers, firewall helper, licenses and translated instructions. No previous mod installation is required. The source ZIP contains the tagged source and build scripts. The symbols ZIP contains the matching Windows PDB for debugging. SHA-256 files accompany the archives.

## Install

1. Close EDF6 and back up `Mods/Plugins/EDF6Coop.dll` if present.
2. Extract the entire full ZIP. Windows: double-click `INSTALL.bat`. Linux/Proton: run `bash install.sh`, or `bash install.sh "/path/to/EARTH DEFENSE FORCE 6"`.
3. Proton needs this Steam launch option: `WINEDLLOVERRIDES="winmm=n,b" %command%`.
4. Install this build on every test participant. Existing settings are preserved.

## Test and send logs

Start a fresh game process for this short test so earlier sessions do not use up the diagnostic limits.

1. Create a room with only the testers. Record who hosts and each player's class.
2. On level ground, stand still and deploy a Luminous Shield. Both players watch for five seconds. Repeat a few times, then repeat while moving or just after landing from a jump or boost. Swap who deploys it.
3. Note the local clock time of each deployment and whether each player sees it. Note whether the invisible shield still blocks attacks.
4. For player jitter, spend at least 15 seconds each standing still, running straight, turning, and jumping or boosting. Note the times and which player jitters. Avoid changing settings or adding players during this test.
5. Close the game. Each tester sends `Mods/Plugins/EDF6Coop.log` from the game folder, along with the observations and host/joiner role. If the log rotated, include `EDF6Coop.log.1` if present.

The log must contain `SHIELD diagnostic build 4` and `PLAYER diagnostic build 4`. Shield lines include movement per frame, damping, orientation, position and effect draw counts. An `unknown` particle count means the reader did not measure a matching particle buffer. It does not mean the effect is empty. Player summaries cover five-second windows with packet gaps, frame gaps, sample age, correction size and whether enhanced sync was active. These maxima describe each window, not average latency.

Shield snapshots stop after 512 samples per process; player summaries stop after 3600 lines. Restart the game for another test after a long session. Restore the backed-up DLL or install stable 3.0.1 after testing.

## Build

See `BUILDING.txt` in the source archive. Windows: double-click `BUILD.cmd` after installing the prerequisites, or run `powershell -ExecutionPolicy Bypass -File build.ps1`. Linux: run `bash build.sh`. Diagnostics are enabled by default in this tag. Both produce `out/EDF6Coop.dll`; `pwsh -File package.ps1` packages the diagnostic on Linux, or `powershell -ExecutionPolicy Bypass -File package.ps1` on Windows.

Automated tests do not verify live multiplayer behavior. This remains a diagnostic build for testers; stable 3.0.1 remains the latest normal release.

## Validation

All 27 non-stress tests passed on native Windows and under Wine, including 15 tests against the supported real EDF.dll. No game tests were skipped. The distributed DLL is the native MSVC build.

The new regression drives the installed plugin update hook with three players and eight NPCs, using EDF.dll's real player classification. It reproduces the missing summaries with diagnostic 3 and passes with diagnostic 4. Live multiplayer behavior still needs testing.
